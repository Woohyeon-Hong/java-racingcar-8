# java-racingcar-precourse

## **🎯 기능 목록**

### 1. 게임을 시작한다.

---

- [x] 게임 시작 문구를 출력한다.
- [x] 등록할 자동차 이름 목록을 입력받는다.
  - [x] `예외 처리`: 이름이 공백인 경우
  - [x] `예외 처리`: 이름이 5자를 초과인 경우
  - [x] `예외 처리`: 이름이 띄어쓰기로 시작하거나 끝나는 경우
  - [x] `예외 처리`: 이름이 서로 중복되는 경우
- [ ] 시도할 횟수를 입력받는다.
  - [ ] `예외 처리`: 양의 정수가 아닌 경우
- [ ] 실행 결과 프롬프트를 출력한다.

### 2. 게임을 진행한다.

---

- [ ] 등록된 자동차들은 해당 턴을 수행한다.
  - [ ] 자동차의 이름을 출력한다.
  - [ ] 자동차는 전진 여부를 결정한다.
  - [ ] 자동차의 이동 결과를 출력한다.
- [ ] 모든 턴이 완료되지 않았으면, 다음 턴을 수행한다.
- [ ] 모든 턴을 완료하면, 게임을 종료한다.


### 3. 게임 결과를 출력한다.

---

- [ ] 최종 우승자를 판단한다.
  - [ ] 자동차들의 최대 이동 거리를 구한다.
  - [ ] 최대 이동 거리와 같은 거리를 이동한 자동차들을 우승자 이름 목록에 추가한다.
- [ ] 최종 우승자 프롬프트를 출력한다.
- [ ] 우승자 이름 목록을 출력한다.
